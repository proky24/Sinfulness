

# SINFULNESS

AARPG


## Popis

Cílem mého ročníkového projektu je vytvoření 2D pixel-art hry, žánrů Dungeon Crawler a RPG, kde hráč bude prozkoumávat rozpadlý hrad, vylepšovat atributy své postavy, zachraňovat své spojence a balancovat jeho herní styl mezi “posvátným” a “zkorumpovaným”
